## Regles de branches
- main = production, develop = integration
- feature/<nom> part de develop ; release/<x.y.z> part de develop ; hotfix/<x.y.z> part de main
- push direct interdit sur main et develop : fusion uniquement par PR avec 1 approbation
- l'auteur d'une PR ne la fusionne jamais ; le relecteur qui approuve fusionne

## Convention de commits
feat:, fix:, docs:, test:, refactor:, chore: + message a l'imperatif
Exemple : feat(cleaning): drop duplicate rows
